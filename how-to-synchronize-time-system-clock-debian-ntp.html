How to synchronize system clock in Debian


Fixing systemd-timesyncd NTP Synchronization in Debian




The timedatectl command is provided by systemd. It allows you to query and change the system clock and its settings, and to enable or disable time synchronization services.

You can also use it to display the current status of time synchronization services such as `systemd-timesyncd.service`.


systemd-timesyncd.service is a system service that synchronizes the local system clock with a remote Network Time Protocol (NTP) server.



To enable system time synchronization:


$ sudo timedatectl set-ntp true

or

$ sudo systemctl enable --now systemd-timesyncd



Check the current time status:


$ timedatectl
Local time: Sun 2026-10-18 22:39:56 CEST
Universal time: Sun 2026-10-18 20:39:56 UTC
RTC time: Sun 2026-10-18 20:44:46
Time zone: Europe/Madrid (CEST, +0200)
System clock synchronized: no
NTP service: active
RTC in local TZ: no

The system clock is not synchronized. The NTP service is active but not working.



Show the current status of the systemd-timesyncd service:

$ timedatectl timesync-status
Server: 130.149.17.8 (130.149.17.8)
Poll interval: 1min 4s (min: 32s; max 34min 8s)
Packet count: 0


$ timedatectl show-timesync --all

The configured server `130.149.17.8` is not responding.



Solution: Update the NTP Configuration


Edit the timesyncd configuration file:

$ sudo nano /etc/systemd/timesyncd.conf

Set a reliable NTP server:
NTP=debian.pool.ntp.org


The resulting file looks like this:

$ cat /etc/systemd/timesyncd.conf
...
# Use 'systemd-analyze cat-config systemd/timesyncd.conf' to display the full config.
#
# See timesyncd.conf(5) for details.

[Time]
NTP=debian.pool.ntp.org
FallbackNTP=0.debian.pool.ntp.org 1.debian.pool.ntp.org 2.debian.pool.ntp.org 3.debian.pool.ntp.org
#RootDistanceMaxSec=5
#PollIntervalMinSec=32
#PollIntervalMaxSec=2048
#ConnectionRetrySec=30
#SaveIntervalSec=60



View the effective configuration (including any drop-ins):

$ systemd-analyze cat-config systemd/timesyncd.conf
# /etc/systemd/timesyncd.conf
#  This file is part of systemd.
#
...
#
# See timesyncd.conf(5) for details.

[Time]
NTP=debian.pool.ntp.org
FallbackNTP=0.debian.pool.ntp.org 1.debian.pool.ntp.org 2.debian.pool.ntp.org 3.debian.pool.ntp.org
#RootDistanceMaxSec=5
#PollIntervalMinSec=32
#PollIntervalMaxSec=2048
#ConnectionRetrySec=30
#SaveIntervalSec=60

# /run/systemd/timesyncd.conf.d/dhcpcd-enp2s0.dhcp.conf
# Generated by dhcpcd from enp2s0.dhcp
[Time]
NTP=130.149.17.8



Note that a DHCP-generated drop-in is still injecting the non-working server. Restart the service to apply the changes:

$ sudo systemctl restart systemd-timesyncd
